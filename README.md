# Bank Project

## Описание:

Bank Project - мой первый учебный проект. Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/didi404-smart/BankProject.git
```
2. Установите poetry:
```
pip install poetry
```
3. Установите зависимости:
```
poetry install
```

## Документация:

masks.py - содержит 2 функции. Функция `get_mask_card_number` принимает на вход номер карты и возвращает ее маску.
Функция `get_mask_account` принимает на вход номер счета и возвращает его маску.

widget.py - содержит функции `mask_account_card`, которая возвращает строку с замаскированным номером. Функция `get_date` форматирует дату.
